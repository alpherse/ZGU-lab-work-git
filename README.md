# ZGU-lab-work-git

Учебный проект для лабораторной по **Git** и **GitHub**

## Описание

Простой скрипт с *арифметическими операциями*

## Установка и запуск

```bash
git clone https://github.com/alpherse/ZGU-lab-work-git.git
cd ZGU-lab-work-git
python src/main.py
```

## Основные функции

- `add(a, b)`: сложение двух чисел
- `multiply(a, b)`: умножение двух чисел
